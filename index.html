Cows and Bulls

Guess the 4-digit secret number.

History

Guess Bulls / Cows

How to play

  • Guess the secret 4-digit number.
  • Bull = correct digit, correct position.
  • Cow = correct digit, wrong position.
  • Advanced mode: secret number has no repeated digits.
  • Beginner mode: digits can repeat.

Scoring system

  • Base points for winning: +5,000 pts
  • Speed bonus: +10 pts / remaining sec
  • Each attempt (after 1st): -150 pts
  • Each hint: -1,000 pts

Keyboard shortcuts

  • Enter — submit guess
  • Esc — clear input
  • Ctrl + Enter — restart game
